# Overworked

2D психологический хоррор для геймджема. Unity 6 (URP 2D), PC, язык игры — английский.

Денни — офисный работник, который после очередных переработок пытается просто добраться
домой. Обычный офис постепенно превращается в кошмар: игрок спускается с 3-го этажа
на 1-й, выполняя задания коллеги Макса из телефона, а в конце попадает в Белую комнату.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | A / D, ← / → |
| Взаимодействие | E |
| Фонарик (со 2-го этажа) | F |
| Телефон | Tab или кнопка на экране |
| Пауза | Esc |

Прыжка и бега нет.

## Ключевые системы

- **Рассудок** — шкала без процентов, падает от событий: 100 → 90 → 50 → 0 по этажам.
- **Пульс** — BPM в углу экрана, растёт при падении рассудка и подскакивает на аномалиях.
- **Телефон** — сообщения от Boss и Max; Max выдаёт задания и с каждым этажом пишет всё страннее.
- **Галлюцинации** — чёрные силуэты и странности с предметами.
- **Финальная мини-игра** — Tiny UFO (одна волна) на компьютере в комнате 1-го этажа.
