# Overworked

2D психологический хоррор для геймджема. Unity 6 (URP 2D), PC, язык игры — английский.

Дэнни — уставший офисный работник, который хочет закончить ночную смену и добраться
домой. Игрок спускается с 3-го этажа на 1-й, выполняя задания из телефона от коллеги Макса
и Босса. Офис превращается в кошмар, Босс начинает обращаться к самому игроку по имени,
а в конце Дэнни оказывается в Белой комнате.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | A / D, ← / → |
| Взаимодействие | E |
| Фонарик (со 2-го этажа) | F |
| Телефон | Tab или кнопка на экране |
| Пауза | Esc |

Прыжка и бега нет.

## Ключевые системы

- **Рассудок** — шкала без процентов, падает на пяти сценарных галлюцинациях: 100 → 90 → 70 → 50 → 25 → 0.
- **Пульс** — BPM в углу экрана, растёт при падении рассудка и подскакивает на аномалиях.
- **Телефон** — сообщения от Max и Boss; Max с каждым этажом пишет всё страннее, Boss всё сильнее давит.
- **Мини-игры** — печать отчёта, считыватель пропуска, настройка сигнала монитора.
- **Галлюцинации** — чёрные силуэты и странности с предметами.
- **Финальная мини-игра** — Tiny UFO (одна волна) на аркадном автомате в комнате отдыха 1-го этажа.
