# DialogueManager (субтитры)

**Владелец:** Программист 3

**Что делает:** показывает строки `DialogueData` внизу экрана: реплики Дэнни, описания объектов
(«ДО» в нарративе) и системный текст — каждый своим стилем. Строки печатаются, висят по времени
(чем длиннее, тем дольше) и сменяются сами. **Space / Enter / клик мышью** — допечатать строку сразу,
повторно — следующая строка. Управление Дэнни не блокирует — это делает сценарий, если нужно.

**Как подключить:** в сцену ничего класть не нужно — `DialogueManager` на корне `_Systems`, плашка
`Subtitles` в `HUD`. UI и стили собирает меню **Overworked → P3 → Build Dialogue UI** (пересоздаёт только
`Subtitles`). Тексты — ассеты `DialogueData`: `Data/Dialogues/` (реплики сцен), `Data/Inspectables/`
(описания объектов). Полный список — [Texts.md](Texts.md).

Песочница `Sandbox_P3` (меню **Build Phone Sandbox**): **Z** — `F3_Start` (Дэнни), **X** — `F3_CharlesDesk`
(описание), **C** — `F2_Monitor201` (системный), **V** — все три подряд (очередь).

**Стили** (поле `styles` на `DialogueManager`, меняются в инспекторе):

| Speaker | Вид |
|---|---|
| Danny | PT Sans, светлый |
| Description | PT Sans, курсив, серо-зелёный |
| System | IBM Plex Mono, зелёный «терминальный» |

**Публичный API:**

| Метод / событие | Что делает |
|---|---|
| `DialogueManager.Instance.Play(data, done)` | проиграть строки по очереди, затем `done`. Если что-то уже играет — встаёт в очередь (done не теряется). Пустые данные — `done` сразу |
| `DialogueManager.Instance.Stop()` | оборвать субтитры и очередь **без** `done` (сама вызывается при смене сцены) |
| `DialogueManager.Instance.IsPlaying` | идут ли субтитры |
| `DialogueManager.Instance.OnLineShown` | показана строка `(Speaker, текст)` — для звука, анимации |

**Тайминги** (инспектор): печать `charsPerSecond` (0 — сразу), висит `holdBase + holdPerChar × символов`.
Время игровое: на паузе субтитры замирают. На паузе и при открытом телефоне пропуск не срабатывает.

**Зависит от:** `TextFormatter` (`{name}`), `PauseMenuUI`, `PhoneManager` (не пропускать при открытом телефоне).
