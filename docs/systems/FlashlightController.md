# FlashlightController

**Владелец:** Программист 4

**Что делает:** фонарик Дэнни на F — 2D Spot Light у руки игрока, светит туда, куда смотрит Дэнни,
разворачивается сразу, без анимации поворота (только влево / вправо). На рассудке ниже 50 % дрожит и иногда коротко гаснет.
F работает, только когда игрок управляет Дэнни (не в телефоне, мини-игре, катсцене).

**Как подключить:** пустой объект `Flashlight` в сцене этажа (Floor_02, Floor_01) + компонент
`FlashlightController`. Свет создаётся сам при старте (или назначьте свой `Light2D` в поле `spot`).
На Floor_02: `availableOnStart` = да, `onAtStart` = нет — игрок включает сам.
Глобальный свет сцены сделать тёмным (`Global Light 2D` → Intensity ~0.05–0.1).

**Публичный API:**

| Метод / событие | Что делает |
|---|---|
| `IsOn`, `Available` | включён ли, доступен ли |
| `SetAvailable(bool)` | недоступный выключается и не включается |
| `Toggle()` | то же, что F |
| `Illuminates(point, maxDistance)` | светит ли на точку (впереди, в пределах луча) — силуэты |
| `event OnToggled(bool on)` | для сценария «пока не включишь фонарик — дальше не пускает» |

**Отладка:** `Sandbox_P4` (тёмный коридор), F — фонарик, L — доступность.

**Зависит от:** PlayerController (позиция, `Facing`, `State`), GameInput, SanityManager, AudioManager.
