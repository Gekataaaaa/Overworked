# Hallucinations: HallucinationManager, HallucinationEvent, силуэты, скример

**Владелец:** Программист 4

**Что делает:** пять сценарных галлюцинаций (паспорт, разделы 11 и 18; NARRATIVE, сцены 1.x–3.3). Каждая —
объект `HallucinationEvent` с дочерними визуалами. **Сейчас весь визуал — квадраты-заглушки**: силуэт —
тёмный прямоугольник, скример — квадрат, вырастающий на весь экран, вспышки и помехи — полноэкранные
прямоугольники. Арт подменяется в префабах (спрайт `Body`, цвета), код не меняется.

**Правила:**
- **Рассудок падает, как только Дэнни видит галлюцинацию** (`ApplySanity`): силуэт попал в кадр,
  вспышка/помехи на экране, скример заполнил экран. Визуал с флагом `SanityOnSeen`.
- **Спайк пульса — в резкий момент** по нарративу (`Hit`: звук + спайк): «лампы резко мигают», «дверь
  с грохотом захлопывается», резкий звук при подходе к силуэту, бросок двойника. Визуал с `TriggersHit`;
  силуэт с `appearAbruptly` появляется сразу целиком и даёт удар в момент появления.
  **Спайк поднимает пульс не выше 140** (`HeartbeatManager.spikeMaxBpm`). Финальный скример —
  испуг 160…180 (`ScreamerHeartbeat`), как в паспорте.
- Визуалы идут по порядку в иерархии; «С предыдущим» — одновременно с соседом сверху.
  Если никто не отметил рассудок/удар — оба в конце.

| Префаб (`Prefabs/Hallucinations/`) | Где | Рассудок (когда) | Удар / спайк (когда) |
|---|---|---|---|
| `H1_Turnstile` | Floor_03, после отказа турникета | → 90, первая вспышка ламп | первая вспышка («резко мигают») |
| `H2_Silhouette` | Floor_02, середина коридора | → 70, силуэт в кадре | подход ближе 2,5 или фонарик — резкий звук, силуэт исчезает |
| `H3_Room201` | Floor_02, Room_201 | → 50, сразу (мигание + помехи, на миг «DD») | сразу (дверь захлопывается) |
| `H4_Room101` | Floor_01, вход в Room_101 | → 25, лампы начинают мигать в такт пульсу | подход к силуэту в углу |
| `H5_FinalScreamer` | Floor_01, выход из Room_102 | → 0, скример на весь экран | бросок двойника (испуг 160…180) |

**В настоящих этажах** (папка `Hallucinations`): Floor_03 — H1, Floor_02 — H2, H3, Floor_01 — H4, H5.
H1–H4 **пока ни к чему не привязаны** (нет зон и шагов сценария) — сами не запускаются, подключим позже
(шаг `HallucinationStep`, `HallucinationTrigger` или `Room.onEnter`). Поставить заново без дублей —
`Overworked → P4 → Add Hallucinations to Floors`.

**Мерцание света.** `LightFlickerVisual` в H1 (резкая вспышка ламп), H3 (бешеное мигание) и H4 (провалы
в такт пульсу) мигает настоящим светом сцены. Список ламп пустой — мигает весь свет, кроме фонарика
(сейчас на этажах это Global Light 2D); к конкретным лампам привяжем позже (поле `lights`).
Для постоянных ламп есть `Effects/LightFlicker` (мерцание от рассудка, в такт пульсу, `Burst(сек)`) —
пока ни на одну лампу не повешен.

**Запуск финала:** `FinalScreamerStarter` (Scripts/Ending) слушает `onDone` аркадного автомата Room_102
(вызывается только при победе в Tiny UFO, ставит флаг `TinyUfoWon`) и `Room.onExit` комнаты 102.
Вышел после победы → ждёт, пока дверь проявит экран и вернёт управление → H5. Без победы выход ничего не запускает.
**В настоящем Floor_01 уже стоит** (Hallucinations: H5_FinalScreamer + H5_Starter_AfterTinyUfo), повторно поставить —
`Overworked → P4 → Add Final Screamer to Floor_01`. Копия песочницы второй скример не добавляет.

**Финал (H5 + `FinalCollapse`, по NARRATIVE 3.3):** фигура приближается за 3 «шага»: видна 0,6 с → пропадает на 0,2 с → резко появляется ближе (спайк +15, до 140) … последний шаг — в 3 юнитах от Дэнни → Дэнни замирает:
«No…» → бросок (квадрат на весь экран), рассудок 0, управление заблокировано → Дэнни падает (`PlayAnim("Fall")`),
экран постепенно темнеет под реплики «{name}… / I can't anymore…» → полный чёрный (теряет сознание) →
звук и пульс резко обрываются → пауза 3 с → `GameManager.LoadFloor(0)` → WhiteRoom.
Реплики — `Data/Dialogues/F1_FinalNo`, `F1_Collapse`.

**Песочница P4 «вся игра»** (`Overworked → P4 → Build Game Sandbox`, `P4GameSandboxBuilder`):
копии `Scenes/Sandbox/Sandbox_P4_MainMenu`, `Sandbox_P4_Floor_03/02/01` — оригиналы не трогаются.
В копиях этажей двери в комнаты работают, на 2 и 1 этажах есть фонарик, галлюцинации стоят на зонах:

| Копия | Зона | Галлюцинация |
|---|---|---|
| Floor_03 | x = 17, перед лестницей (турникет) | H1 |
| Floor_02 | x = −6, середина коридора | H2 |
| Floor_02 | Room_201, x = 2 | H3 |
| Floor_01 | Room_101, точка входа | H4 |
| Floor_01 | выход из Room_102 в коридор, только после победы в Tiny UFO (`FinalScreamerStarter`) | H5 → WhiteRoom |

Запускать с `Sandbox_P4_MainMenu` (или с копии этажа). `P4SandboxRoute` (только редактор) подменяет
загрузку оригиналов (`Floor_0X`, `MainMenu`) на копии, поэтому лестницы и меню ведут по копиям;
WhiteRoom — настоящая. Копии пересоздаются сборщиком из оригиналов — руками в них не править.

**Как подключить в настоящие этажи (владельцам сцен):** перетащить префаб в папку `Hallucinations` сцены
(позиция не важна: силуэты ставятся относительно игрока, `spawnNearPlayer`) и запустить шагом
`HallucinationStep` из сценария, зоной `HallucinationTrigger` или `HallucinationManager.Instance.Play(h, done)`.
После H5 управление не возвращается — `FinalCollapse` сам доводит до WhiteRoom.

**Публичный API:**

| Метод / поле | Что делает |
|---|---|
| `HallucinationManager.Play(h, done)`, `Current` | запустить; идущая галлюцинация |
| `HallucinationEvent.Play(done)`, `ApplySanity()`, `Hit()` | запуск; рассудок (увидел); удар (звук + спайк) |
| `IsPlaying`, `SanityApplied`, `HasHit`, `HasPlayed`, `event OnHit`, `event Finished` | состояние и события |
| `SanityAfter`, `HeartbeatSpike`, `Duration`, `ScreamerHeartbeat` | рассудок после, спайк (до 140), испуг скримера |
| `Sound`, `SoundOnStart`, `LockPlayer`, `KeepLocked` | звук удара, блокировка управления |
| `HallucinationTrigger`: `hallucination`, `requireVisited`, `requirePlayed` | зона; пустая — отметка «был здесь» |
| `FlashlightController.Illuminates(point, maxDistance)` | светит ли фонарик на точку |

Визуалы (`HallucinationVisual`: `WithPrevious`, `Delay`, `TriggersHit`, `SanityOnSeen`, `Cleanup()`):
`SilhouetteBehaviour`, `ScreamerVisual`, `ScreenFlashVisual` (вспышки, в т. ч. в такт пульсу),
`StaticNoiseVisual` (помехи + надпись), `DialogueVisual` (реплики). Полноэкранные — на своём Canvas
поверх HUD (sortingOrder 900).

**Отладка:** `Sandbox_P4` и копии этажей: Shift+1…5 — H1–H5 сцены, U — вернуть управление
(F1–F5 заняты отладкой P1: меню и этажи). Тесты: `Tests/PlayMode/HallucinationTests` (в т. ч. на настоящем Floor_01)
(рассудок при виде силуэта, спайк ≤ 140, скример только после победы в Tiny UFO и выхода из 102 → WhiteRoom, лестница ведёт в копию).

**Зависит от:** SanityManager, HeartbeatManager, AudioManager, PlayerController, FlashlightController,
DialogueManager, FadeController, GameManager/SceneTransitionManager.
