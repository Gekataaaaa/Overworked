# MainMenu и пролог

**Владелец:** Программист 1

**Что делает:** сцена `MainMenu`: экран OVERWORKED с кнопками **Continue / New Game / Quit**.
- **New Game** → затемнение → пролог-терминал в стиле Arch Linux:
  1. **лог загрузки** (`Data/Dialogues/Prologue_Boot`): ядро с метками времени и службы systemd,
     строки выводятся целиком с неровными паузами 0.015–0.12 с, экран прокручивается (24 строки),
     после `[FAILED]` пауза подольше; **любая клавиша — пропустить**;
  2. экран очищается, заголовок tty1 и приглашение (`Prologue_Intro`) печатаются посимвольно,
     затем `Enter your name: █`.

  Всё время терминала — **CRT-эффект** как у автомата Tiny UFO (сканлайны, рыбий глаз, виньетка,
  мерцание): `UI/TerminalCrt.cs` на камере меню + материал `Materials/TerminalCRT` (шейдер из
  `Microgames/gc26_spinv/Shaders/CRT.shader`, свои значения). Холст на время пролога переводится
  в Screen Space – Camera, иначе эффект его не видит. Затемнение `FadePanel` — поверх CRT. Имя — 1–16 символов, **только латиница**: A–Z, цифры,
  пробел и дефис (не первым символом); остальное поле не принимает. Имя сохраняется в
  `GameManager.Instance.State.PlayerName`, печатается приветствие, загружается Floor_03.
- **Continue** — появляется, только если игрок вышел в меню **через паузу** (Esc → Main Menu).
  Возвращает ровно туда же, без пролога и ввода имени. При первом запуске игры её нет.
- **Quit** — выход.

**Как работает Continue (`Scripts/Core/ResumePoint.cs`)** — сохранений на диске нет, всё в памяти
до конца запуска игры:
- Пауза → Main Menu (`GameManager.LeaveToMainMenu`) запоминает сцену, позицию Дэнни, рассудок
  и какие камеры Cinemachine были включены (игрок мог стоять в комнате).
- Continue (`GameManager.ContinueGame`) загружает ту сцену, после `Start()` её объектов ставит
  Дэнни на место, возвращает рассудок (поверх стартового из `FloorSettings`) и камеру.
- Имя, флаги, задания и телефон живут в `_Systems` и не сбрасываются.
- Точка стирается: New Game, переход в WhiteRoom, после использования. Перезапуск игры — тоже
  (только New Game).

**Важно для P2–P4:** Continue заново загружает сцену этажа, поэтому её триггеры и сценарные
цепочки снова «свежие». Одноразовые события (галлюцинация, сообщение, подобранный предмет)
должны проверять и ставить флаг в `GameManager.Instance.State.Flags`, иначе после Continue
они сработают повторно.

**Как подключить:** сцена собирается меню **Overworked → P1 → Build Main Menu**
(`Editor/MainMenuBuilder.cs`). Сборщик сам импортирует TMP Essential Resources, создаёт
динамические шрифты и ассеты текстов, если их нет; повторный запуск пересоздаёт только
`MainMenu Canvas`.

**Тексты:** `Data/Dialogues/Prologue_Boot` (лог загрузки), `Prologue_Intro` (экран входа; **последняя
строка — подпись у поля ввода**) и `Prologue_Welcome` (поддерживает `{name}`). Rich text разрешён:
`[  <color=#7CFF8A>OK</color>  ]`.

**Шрифты** (`Fonts/`, лицензия OFL — файлы `*-OFL.txt` рядом):
- `PTSans SDF` — основной, назначен шрифтом TMP по умолчанию (новые тексты берут его сами);
- `IBMPlexMono SDF` — моноширинный «терминальный» (пролог, мониторы).

Оба динамические: латиница и кириллица запечены, остальные символы досоздаются на лету.

**Публичный API:**

| Метод / свойство | Что делает |
|---|---|
| `PrologueTerminal.Begin()` | запуск пролога (вызывает `MainMenuUI`) |
| `GameManager.Instance.LeaveToMainMenu()` | в меню с запоминанием места (так делает пауза) |
| `GameManager.Instance.CanContinue` | есть ли куда вернуться |
| `GameManager.Instance.ContinueGame()` | вернуться в запомненное место |
| `PlayerController.Instance.Teleport(Vector3)` | поставить Дэнни в позицию |

**Зависит от:** GameManager, FadeController, TextFormatter, DialogueData.
