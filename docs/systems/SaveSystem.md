# SaveSystem — сохранение на диск

**Владелец:** Программист 1

**Что делает:** Continue после перезапуска игры продолжает **с того места, где остановились**. Файл —
`Application.persistentDataPath/overworked_save.json` (Windows: `%USERPROFILE%\AppData\LocalLow\Overworked Team\Overworked`).
В нём:
- **состояние игры:** имя, этаж, флаги `GameState.Flags`, задания (выполненные по Id и активные), история телефона;
- **снимок этажа:** позиция, направление и комната Дэнни, рассудок; какие объекты сцены включены / выключены /
  уничтожены относительно исходной сцены (пути с номерами среди соседей); одноразовые флажки компонентов
  `Overworked` — поля из списка `StateFields`: `used`, `locked`, `doorLocked`, `fired`, `done`, `won`, `started`,
  `onboarded`, `introDone`, `visited`, `denied`, `shown`, `shownOnce`, автосвойства `HasPlayed`, `SanityApplied`, `HasHit`, `Available`, `IsOn`, `Visited`
  (сценарий отыгран, триггер сработал, предмет использован, дверь заперта, фонарик подобран/включён,
  турникет уже отказал своей карте, описание объекта уже показано…).

**Когда пишется:**
- при входе на этаж — чекпоинт «этаж с начала» (без снимка);
- автосохранение раз в 4 с, при выходе в меню из паузы и при закрытии игры — со снимком, но только если Дэнни
  свободен и ничего не идёт (`StoryBusy`: реплика, сценарий, галлюцинация). Полусыгранный сценарий сохранить
  нельзя — тогда в файле остаётся прошлое сохранение (на несколько секунд раньше).

**Continue** (`GameManager.ContinueFromSave`): состояние игры выставляется сразу, этаж грузится, снимок
применяется в `sceneLoaded` — после `Awake`, до `Start` объектов: стартовые сценарии видят «уже отыграно» и не
повторяются (подсказка управления, онбординг HUD, вступление Белой комнаты). Кадром позже (после `FloorSettings`)
Дэнни встаёт на место, комната становится текущей без `onEnter` (`Room.RestoreInside`), рассудок — сохранённый.
Если этаж ещё в памяти под меню (пауза → Main Menu в этой сессии) — берётся он.
New Game стирает файл (`MainMenuUI`), конец игры (Белая комната → титры → `GameManager.LoadMainMenu`) — тоже.

**Как подключить:** ничего класть в сцену не нужно — `SaveSystem` статический, сам подписывается на загрузку сцен
и создаёт объект автосохранения. Задания и сообщения находит по Id / имени в `Resources/SaveRegistry`
(`Data/Resources/SaveRegistry.asset`); реестр обновляется сам после каждой перекомпиляции (`SaveRegistryRefresher`),
вручную — **Overworked → P1 → Data → Refresh Save Registry**.

**Новый одноразовый флажок** (что-то «уже случилось» и не должно повториться после загрузки) — назвать поле
одним из имён `StateFields` или добавить имя туда. Если объект прячет/показывает что-то в `Awake` по такому
флажку — перенести в `Start` (снимок применяется между ними; пример — `WhiteRoomTrigger`).

**Публичный API:**

| | |
|---|---|
| `SaveSystem.HasSave` | есть ли читаемое сохранение |
| `SaveSystem.SaveNow()` | сохранить сейчас со снимком (если можно) |
| `SaveSystem.Load()` | выставить состояние из файла, вернуть этаж (−1 — нет / не читается) |
| `SaveSystem.Delete()` | стереть файл |
| `SaveSystem.StoryBusy()` | идёт ли реплика / сценарий / галлюцинация |
| `GameManager.CanContinueAny` / `ContinueFromSave()` | для главного меню |
| `ObjectiveManager.Restore(...)`, `MessageManager.Restore(...)` | восстановление без тостов и повторной выдачи |

**Зависит от:** `GameManager`, `ObjectiveManager`, `MessageManager`, `SaveRegistry`, `Room`, `PlayerController`.

**Известные ограничения / TODO:**
- Не сохраняются: положение сдвинутых объектов (кроме Дэнни), состояние внутри идущих сценариев, ожидание
  «прочитай сообщение» (пока сценарий ждёт прочтения, автосохранение ждёт вместе с ним).
- Пути объектов — по иерархии сцены: если сцену пересобрать билдером между сохранением и загрузкой, снимок
  частично не применится (непрочитанные пути пропускаются).
- Чекпоинты пишутся, только если в этой сессии игра прошла через главное меню: этаж, запущенный прямо из
  редактора, не затирает настоящее сохранение.
- Формат версионирован (`Version` = 2); другая версия не читается — Continue не показывается.
