# Footsteps — шаги Дэнни

**Владелец:** Программист 1

**Что делает:** при ходьбе на каждом кадре анимации, где нога встаёт на пол, звучит один шаг — звук идёт
ровно в такт картинке. Кадры шага — `Danny_Walk_2` (0.5 с) и `Danny_Walk_5` (1.15 с) цикла `Danny_Walk`
(1.4 с, два шага за цикл). Отдельные шаги вырезаются из длинной записи `Audio/SFX/SFX_Footsteps` (90 с шагов
по деревянному полу) один раз за игру: в записи ищутся удары по громкости, из них берутся `maxSteps` (12)
равномерно по записи, все приводятся к одной громкости; запись после нарезки выгружается из памяти.
Шаги чередуются случайно, без повтора подряд, с разбросом тона `pitchJitter` (±4 %).

**Как подключить:** компонент `Footsteps` уже на префабе `Prefabs/Player/Player` (рядом с `PlayerAnimator`).
Поля: `stepsRecording` — запись, `footfallFrames` — спрайты кадров шага, `body` — SpriteRenderer Дэнни,
`volume` (0.35). Нарезка: `stepLength` (0.35 с — макс. длина шага), `minGap` (0.3 с — минимум между ударами),
`threshold` (0.3 — порог удара). Импорт записи: Decompress On Load, Force To Mono, Preload Audio Data
выключен (грузится только на время нарезки). Новая анимация ходьбы — поменять `footfallFrames`.

Префаб Player стоит на всех этажах (Floor_03, Floor_02, Floor_01, WhiteRoom) без переопределений —
шаги есть везде; в новой сцене этажа ставить именно префаб.

**Публичный API:** нет (компонент сам следит за кадром). Звук — через
`AudioManager.PlaySfxPitched(clip, volume, pitch)` на канале SFX.

**Зависит от:** `PlayerController` (`IsMoving`), `AudioManager`, анимация `Danny_Walk`.

**Известные ограничения / TODO:**
- Сколько шагов вырезано — пишется в консоль: `[Footsteps] из SFX_Footsteps вырезано шагов: N`. Если N мало
  или в шагах слышно шарканье/двойные удары — подстроить `threshold` / `minGap` / `stepLength`.
- Звук шага один на все полы (дерево); на других покрытиях — тот же.
