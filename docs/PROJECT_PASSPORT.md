# OVERWORKED — паспорт проекта и техническая структура

Unity 6 (URP 2D) • 2D Psychological Horror • PC • Game Jam

> Паспорт описывает **как** устроена игра технически. **Что** происходит по сюжету —
> в [нарративном документе](narrative/NARRATIVE.md); при расхождении сюжет берётся
> из нарратива, а паспорт обновляется под него. Решения команды — в конце документа.

**Язык игры — английский** (все тексты, сообщения, субтитры, UI). Нарратив написан
на русском; английская версия для игры — [NARRATIVE_EN.md](narrative/NARRATIVE_EN.md),
из неё тексты переносятся в ScriptableObject в `Data/`.

## 1. Общая информация

| | |
|---|---|
| Название | Overworked |
| Жанр | 2D Psychological Horror / Narrative |
| Платформа | PC (Windows) |
| Движок | Unity **6000.5.6f1**, URP 2D — у всей команды строго одна версия |
| Ввод | Input System (новый) |
| Команда | 4 программиста + 2 художника |
| Вид | 2D side view |

**Персонажи:** Дэнни (Danny) — главный герой; Макс — коллега, пишет в телефон;
Босс — руководитель, пишет в телефон и со временем обращается напрямую к игроку;
чёрные силуэты — фантомы галлюцинаций; Чарльз — пропавший коллега (только упоминается).

**Управление**

| Действие | Клавиша |
|---|---|
| Движение | A / D и ← / → (прыжка и бега нет) |
| Взаимодействие | E (в мини-игре «Считыватель» — удержание E) |
| Фонарик | F (с Floor_02) |
| Телефон | UI-кнопка **и** клавиша Tab |
| Пауза | Esc |

Пока открыт телефон, Дэнни не двигается (ввод движения блокируется), мир не на паузе.

**Главная идея.** Дэнни — уставший офисный работник, который хочет закончить смену
и добраться домой. Офис постепенно превращается в кошмар, а Босс всё сильнее давит —
и в итоге обращается к самому игроку. В конце становится ясно: Белая комната — образ
больничной палаты, Дэнни всё это время был в тяжёлом состоянии.
Маршрут: Пролог → Этаж 3 → Этаж 2 → Этаж 1 → Белая комната.

## 2. Главная игровая цель

Игрок выполняет задания, которые приходят в телефон (от Макса, на Floor_01 — от Босса).
Переход дальше закрыт «замком» этажа, пока задание не выполнено:

| Этаж | Что блокирует путь | Как открывается |
|---|---|---|
| Floor_03 | Турникет | Пропуск Макса + мини-игра «Считыватель пропуска» |
| Floor_02 | Тёмный коридор, затем лестница | Включить фонарик; выполнить задание в Room_201 |
| Floor_01 | Запертая дверь 102 | Ключ из Room_101 → Room_102 (комната отдыха) → Tiny UFO |

На предыдущий этаж вернуться нельзя. Комнаты находятся внутри сцены текущего этажа.

## 3. Основной игровой цикл

```
Исследование → Сообщение (Макс / Босс) → Новое задание → Поиск объекта / мини-игра
→ Задание выполнено → Галлюцинация (рассудок падает) → Следующее сообщение
→ Путь открыт → Следующий этаж
```

## 4. Структура игры

```
MAIN MENU → PROLOGUE → FLOOR 03 → FLOOR 02 → FLOOR 01 → (FINAL SCREAMER)
→ WHITE ROOM → (CREDITS) → MAIN MENU
```

Unity-сцены: `MainMenu`, `Floor_03`, `Floor_02`, `Floor_01`, `WhiteRoom`.

- **PROLOGUE** — не сцена, а UI-последовательность в `MainMenu` после «Начать игру».
- **FINAL SCREAMER** — скриптовое событие в конце `Floor_01`.
- **CREDITS** — UI-панель в конце `WhiteRoom`.
- Комнаты не являются отдельными сценами.

## 5. Пролог — авторизация

После «Начать игру» экран темнеет, открывается окно старого корпоративного терминала
(тускло-зелёный моноширинный текст, мигающий курсор): система учёта рабочего времени
просит ввести имя оператора. Игрок вводит имя, Enter →
«WELCOME TO THE STAFF, {name}. DO NOT LEAVE YOUR WORKPLACE.» → затемнение,
гул ламп и стук клавиатуры → загрузка `Floor_03`.

Имя хранится в `GameState.PlayerName` и подставляется в тексты через `{name}`
(сообщения Босса, реплики Дэнни, документы в Room_201 / Room_101, Белая комната).
Пустое имя не принимается, длина ≤ 16 символов.

## 6. Этаж 3 (Акт 1)

Рассудок 100 → 90. Офис привычный, но пустой; редкие лампы мерцают. Отдельных комнат
нет, кроме **кухни** (вход через дверь, как в комнату). Локации: опенспейс, коридор
с закрытыми дверями, кухня, турникет, лестница.

**Сценарий этажа:**
1. **Старт за компьютером** — мини-игра «Печать отчёта» (заскриптованный провал
   на 60 %), реплики Дэнни. Затем по очереди появляются элементы HUD (рассудок + пульс,
   телефон, подсказка управления) — после этого игрок получает управление.
2. **Стол Чарльза** — описание при приближении, E → записка на весь экран,
   тост «Получено: Записка Чарльза».
3. **Сообщение Макса** при выходе в коридор → задание «Забрать пропуск Макса».
   Неправильные двери: «Это не похоже на кухню».
4. **Кухня** — пропуск у кофеварки (Pickup), задание выполнено.
5. **Сообщение Макса** при выходе из кухни.
6. **Турникет** со своей картой → «ОТКАЗАНО В ДОСТУПЕ» → сообщение Босса →
   после закрытия телефона **Галлюцинация 1** (100 → 90).
7. **Турникет** с картой Макса → мини-игра «Считыватель пропуска» → лестница.

Необязательные объекты: настенные часы, пустой кулер, доска «Сотрудник месяца».
Сообщения: Max — 2, Boss — 1.

## 7. Этаж 2 (Акт 2)

Рассудок 90 → 50. Почти все лампы перегорели, основной свет — фонарик.
Одна комната — `Room_201`. Появляются чёрные силуэты.

**Сценарий этажа:**
1. **Тёмная площадка** — фонарик уже в руках у Дэнни, подсказка F. Пока игрок
   не включит фонарик, дальше не пускает. Включение → сообщения Макса и Босса →
   задание «Проверить документы в комнате 201».
2. **Коридор** — необязательные объекты (разбитая лампа, кружка с плесенью).
   В триггере посередине — **Галлюцинация 2** (90 → 70): сгорбленный силуэт лицом
   к стене на границе света; при приближении или наведении фонарика — резкий звук,
   искажение, силуэт исчезает. Сразу после — **сбой управления**: несколько секунд
   Дэнни продолжает идти после отпускания клавиши; Дэнни поворачивается к экрану
   и говорит с игроком.
3. **Room_201** — ящик стола: графики смен, в конце строка «{name} — Status: Active».
   Компьютер → мини-игра «Настройка сигнала монитора» → «REPORT NOT CLOSED.
   SHIFT CONTINUES.» → задание выполнено → **Галлюцинация 3** (70 → 50): дверь
   захлопывается, свет мигает, помехи, звуковой удар; на помехах экрана на мгновение
   проступает надпись **«DD»**. Затем экран гаснет, дверь открывается. Событие ничем
   не объясняется.
4. Сообщения Макса («НЕ СПУСКАЙСЯ…») и Босса (впервые упоминает {name}).
5. **Попытка пойти назад** после комнаты → уведомление «Do you still want Danny
   to keep working here?», Дэнни останавливается. Дальше — лестница вниз.

Сообщения: Max — 2 (тревожные и странные), Boss — 2.

## 8. Этаж 1 (Акт 3)

Рассудок 50 → 0. Офис неестественно вытянут, подтёки на стенах, лампы постоянно мигают.
Сообщения Макса — глитч-символы. Босс обращается напрямую к игроку по имени.

**Сценарий этажа:**
1. **Коридор** — главный выход (E: заперт, за стеклом пустота), дверь Room_102
   (E: заперта, «ключ в комнате 101») → задание «Найти ключ в комнате 101».
   Сообщения Макса (глитч) и Босса; Дэнни смотрит на игрока и говорит с ним.
   Необязательные объекты: тёмное стекло у поста охраны, стопка заявлений об увольнении.
2. **Room_101** — **Галлюцинация 4** (50 → 25): лампы мигают в такт пульсу, силуэт
   в углу. Бормочущий человек на стуле: E → сжимается в точку и исчезает
   (`PersonInteractable`). Ящик: ключ от 102 + бейдж «{name} — Senior Operator»
   → задание выполнено → новое задание «Завершить работу в комнате 102».
   Сообщения Макса (глитч) и Босса («отправь его в 102-ю, там комната отдыха»).
3. **Room_102 — комната отдыха** — ключ из 101 открывает дверь 102. Внутри стол,
   стулья, автомат с напитками и аркадный автомат. Сообщение Босса; автомат → **Tiny UFO**.
4. **Финальный скример** — при выходе из Room_102 (см. раздел 10).

Лестницы на этаже 1 **нет**. Сообщения: Max — 2 (глитч), Boss — 3.

## 9. Мини-игры

Все мини-игры — UI-оверлей поверх сцены этажа; на время мини-игры управление Дэнни
заблокировано. Общий интерфейс `IMiniGame.Begin(Action<bool> onFinish)` (true — победа, false — выход).

| # | Название | Этаж | Механика | Итог |
|---|---|---|---|---|
| 1 | Печать отчёта | 3 | Нажимать подсвеченные клавиши (5 шт.) | **Всегда провал**: на 60 % текст превращается в символы, звук ошибки, шкала сбрасывается |
| 2 | Считыватель пропуска | 3 | Удерживать E, отпустить, когда ползунок в зелёной зоне | Попал → «ACCESS GRANTED»; промах → повтор |
| 3 | Настройка сигнала монитора | 2 | Два ползунка «Частота» и «Резкость», навести чёткость | Чётко → скрытое сообщение |
| 4 | Tiny UFO | 1 | Меню Play / Quit, одна волна (копия 4-й волны Tiny UFO) | Победа → задание выполнено; поражение → волна заново; Quit → выход без выполнения |

**Tiny UFO** — готовая игра автора. Исходники лежат в репозитории в
[`External/TinyUFO/`](../External/TinyUFO/README.md) (вне `Assets/`, Unity их не видит).
Переносятся в `Assets/Core/` и `Assets/Microgames/gc26_spinv/` **по исходным путям**
(на них завязан генератор сцены), запускаются additive-сценой поверх `Floor_01`.
Лишнее (прогресс, лидерборд, достижения, туториалы, аркада, настройки) выключается.

Управление в мини-игре 3 — клавиатурой: W/S выбирают ползунок, A/D двигают
(мышь тоже работает).

## 10. Финальный скример и White Room

```
Победа в Tiny UFO → выход из Room_102 → звук за спиной, рывок камеры
→ фантомный двойник Дэнни бросается в камеру + аудиоудар
→ рассудок 25 → 0, оглушительный пульс, потеря фокуса, управление заблокировано
→ Дэнни падает, последние реплики → звук обрывается → загрузка WhiteRoom
```

**White Room** — отдельная сцена: белое пространство и линия пола, HUD скрыт,
слышен только пульс. Дэнни может двигаться только вправо и говорит с игроком
по имени. Появляется кровать; Дэнни ложится автоматически при подходе. Пульс
40 → 30 → 20 → 10. Затем появляются звуки аппарата ИВЛ и писк кардиомонитора —
становится ясно, что это больничная палата. Пульс → 0, длинный непрерывный сигнал,
экран растворяется в белом → титры → MainMenu. Никакого морального текста.

## 11. Рассудок

Процент рассудка игрок НЕ видит — только шкала в левом верхнем углу (появляется
в начале Floor_03). Рассудок меняется **только событиями** (галлюцинациями), не от
времени и расстояния. Шкала плавно приходит к новому значению примерно за 1 секунду.

| Событие | Рассудок |
|---|---|
| Галлюцинация 1 — турникет, Floor_03 | 100 → 90 |
| Галлюцинация 2 — силуэт в коридоре, Floor_02 | 90 → 70 |
| Галлюцинация 3 — Room_201, Floor_02 | 70 → 50 |
| Галлюцинация 4 — Room_101, Floor_01 | 50 → 25 |
| Финальный скример, Floor_01 | 25 → 0 |

Значения сценарные, поэтому галлюцинация задаёт **целевое значение** (`SetSanity(70)`),
а не урон — так шкала всегда совпадает с нарративом. При загрузке этажа рассудок
выставляется в его стартовое значение (100 / 90 / 50) — это нужно для запуска сцены
из редактора.

## 12. Архитектура Sanity

```
SanityManager
├── Current / Target
├── SetSanity(target)          # сценарные галлюцинации
├── (Update) плавный переход Current → Target
└── event OnSanityChanged(float current01)
       ├── SanityBarUI
       ├── HeartbeatManager       (базовый BPM)
       ├── PostFXController       (виньетка, шум, аберрация)
       └── AudioManager           (гул, искажения)
```

## 13. Сердцебиение

Heartbeat — не здоровье и не HP, а визуально-звуковой индикатор напряжения.
В правом верхнем углу — иконка и BPM (появляется в начале Floor_03).

- **Базовый BPM зависит от рассудка**: 100 % → ~70 BPM, 0 % → ~120 BPM (подбирается).
- **Спайки**: во время галлюцинаций пульс резко повышается и за несколько секунд
  возвращается. В Room_101 лампы мигают в такт пульсу.
- **Скример**: пульс «оглушительный» (максимальная громкость, частый).
- **WhiteRoom**: скриптово 40 → 30 → 20 → 10 → 0 и непрерывный сигнал.

## 14. Телефон и сообщения

Открывается игроком вручную (кнопка или Tab), автоматически не открывается.
Контакты Boss и Max, сообщения можно перечитывать, отвечать нельзя. Новое сообщение —
вибрация (звук + тряска иконки), тост и звук. История сохраняется между этажами.

| Контакт | Floor_03 | Floor_02 | Floor_01 |
|---|---|---|---|
| Max | дружелюбно, просит забрать пропуск | тревожно, странно, «НЕ СПУСКАЙСЯ» | глитч-символы, двоичный код |
| Boss | рабочее давление, аннулирует пропуск | лишает премии, впервые упоминает {name} | обращается к игроку по имени, ведёт к финалу |

**Триггеры доставки:** вход в зону, взаимодействие с объектом, завершение задания,
включение фонарика, событие сцены. Несколько сообщений подряд (Макс, следом Босс)
приходят цепочкой.

**Событие после прочтения.** Некоторые события начинаются, когда игрок **закрыл
телефон** после конкретного сообщения (например, Галлюцинация 1 после сообщения
Босса у турникета). Для этого у `MessageData` есть `OnReadEvent`.

Глитч-текст Макса хранится в данных как готовая строка (символы, двоичный код,
зачёркивание) — генерировать его не нужно.

## 15. Задания

```
Сообщение / событие → ObjectiveManager.Start(objective) → карточка Objective (правый верх)
Игрок выполняет → ObjectiveManager.Complete() → ☑ → (опц.) следующее сообщение / событие
```

| Этаж | Задание |
|---|---|
| Floor_03 | Забрать пропуск Макса |
| Floor_02 | Проверить документы в комнате 201 |
| Floor_01 | Найти ключ в комнате 101 → Завершить работу в комнате 102 (комната отдыха, Tiny UFO) |

## 16. Interaction System

Универсальная кнопка E. Подходя к объекту, игрок видит подсказку `[E] <действие>`
(текст задаётся на объекте: «Take note», «Pick up pass», «Enter room 201»…).
Если в зоне несколько объектов — выбирается ближайший.

**Описание при приближении.** У многих объектов есть текст-описание (в нарративе — «ДО»),
который показывается автоматически при подходе, без нажатия E. После описания могут
идти реплики Дэнни (субтитры).

| Объект | Действие |
|---|---|
| Inspectable | Описание + реплики Дэнни (часы, кулер, кружка, стекло…) |
| Note | Текст на весь экран + тост «Получено: …» |
| Pickup | Предмет исчезает, тост «Получено: …», шаг задания закрыт (без инвентаря) |
| Drawer | Открыть, показать содержимое (описание), выдать предмет |
| Computer | Запустить мини-игру |
| Person | Сжатие в точку, исчезновение |
| Door | Войти / выйти из комнаты; запертая — показать текст («Это не похоже на кухню») |
| Turnstile | Проверка пропуска → мини-игра «Считыватель» |
| Arcade | Запустить Tiny UFO |
| Stairs | Переход на следующий этаж |

Все объекты реализуют `IInteractable` (общая база `InteractableBase`). Связь с заданиями — поля
`requiresObjective` / `completesObjective` у объекта, зона `ObjectiveTrigger` и `ObjectiveGiver` для UnityEvent
(подробно — [docs/systems/InteractionSystem.md](systems/InteractionSystem.md)).

## 17. Скриптовые сцены

Нарратив состоит из коротких постановочных сцен: реплики, пауза, сообщение, галлюцинация,
блокировка управления. Они собираются из шагов (`ScriptedSequence`):

- показать реплику Дэнни (субтитр) / описание;
- доставить сообщение и ждать, пока игрок его прочитает и закроет телефон;
- заблокировать / вернуть управление;
- проиграть анимацию Дэнни (встать со стула, остановиться, **повернуться к экрану**, упасть);
- показать элемент HUD (онбординг на Floor_03);
- запустить галлюцинацию / мини-игру / задание;
- включить или выключить объект, открыть запертую дверь (Room_102 ключом);
- fade, пауза.

**Особые эффекты управления:**
- **Сбой ввода** (Floor_02): персонаж продолжает идти после отпускания клавиши несколько секунд.
- **Запрет возврата** (Floor_02): триггер позади игрока показывает уведомление и останавливает Дэнни.
- **Только вправо** (WhiteRoom).

## 18. Галлюцинации

Все основные галлюцинации — **сценарные** (их пять, см. раздел 11). Каждая — набор:
звук + визуал (силуэт / мигание / помехи / размытие) + спайк пульса + `SetSanity`.

```
Триггер (зона / событие / закрытие телефона) → HallucinationEvent
→ Sound + Visual + Heartbeat spike + SetSanity → Event ends
```

Визуальные типы: **чёрные силуэты** (появляются на Floor_02 и Floor_01, финальный —
двойник Дэнни) и **странности окружения** (мигающий свет, помехи на мониторах,
размытие, захлопнувшаяся дверь). Дополнительные мелкие аномалии без потери рассудка
(звон в ушах, фантомный стук клавиатур) — по желанию, режутся первыми.

## 24. Связь систем (пример — турникет на Floor_03)

```
Turnstile (E, своя карта) → Toast "ACCESS DENIED" → MessageManager.Deliver(F3_Boss_01)
Игрок читает и закрывает телефон → OnReadEvent → HallucinationEvent "H1"
   ├── LightFlicker + PostFX (размытие) + звон + стрекот клавиатур
   ├── HeartbeatManager.Spike()
   └── SanityManager.SetSanity(90)
→ DialogueManager (реплики Дэнни)
Turnstile (E, карта Макса) → MiniGameHost.Open(CardReader) → победа → Stairs доступна
```

Системы общаются через C#-события / методы менеджеров, без `FindObjectOfType`
и без прямых ссылок «объект знает про UI».

## 25. GameManager и постоянные системы

GameManager хранит `GameState` (CurrentFloor, PlayerName, флаги) и глобальные ссылки,
не превращаясь в гигантский контроллер.

Между сценами живут рассудок, история телефона, имя игрока и HUD. Поэтому префаб
**`_Systems`** (GameManager, SanityManager, HeartbeatManager, PhoneManager,
MessageManager, ObjectiveManager, DialogueManager, AudioManager, HUD Canvas)
(`Assets/_Project/Prefabs/Systems/Resources/_Systems.prefab`) создаётся один раз через
`Bootstrap` до загрузки первой сцены и помечается `DontDestroyOnLoad`. Если сцена
запущена прямо из редактора, `Bootstrap` сам создаёт `_Systems` и ставит
тестовое имя.
