# Overworked — задачи по графике

Список всех арт-задач для игры: спрайты, анимации, фоны, пропсы, мини-игры, UI и визуальные эффекты.
Отмечайте выполненное через `[x]`. Рядом с задачей можно указывать исполнителя: `— @имя`.

**Общий стиль:** 2D, вид сбоку. Палитра основных локаций — грязно-зелёные, серые и выцветшие синие тона; окружение постепенно деградирует от Акта 1 к Акту 3.

**Ответственные** (паспорт, раздел 28): **Художник 1** — персонажи (раздел 1); **Художник 2** — окружение, пропсы, UI мини-игр, терминал пролога (разделы 2–4). UI/HUD (раздел 5) и VFX (раздел 6) рисуются совместно с программистами 3 и 4 (телефон/HUD и PostFX/свет).

**Надписи в игре** (таблички, записка, штамп, тексты на экранах) делаются на английском по [`narrative/NARRATIVE_EN.md`](narrative/NARRATIVE_EN.md); русский текст ниже — для ориентира.

**Легенда приоритетов:** 🔴 нужно для прохождения · 🟡 важно для атмосферы · 🟢 полировка
